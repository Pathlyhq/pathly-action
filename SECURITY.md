# Security Policy

## Supported versions

We support the latest released version of this project. Please upgrade before reporting issues that may already be fixed.

## Reporting a vulnerability

**Do not** open a public GitHub issue for security vulnerabilities.

Email **security@pathlyhq.com** with:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept when available
- Affected package version and environment

We aim to acknowledge reports within a few business days.

## Dependency / supply-chain reports

For vulnerable third-party dependencies in this repository, contact **security@pathlyhq.com** (same inbox). Include the package name, version, and advisory ID when known.

## Privacy

For privacy or data-protection questions (GDPR, personal data), contact **privacy@pathlyhq.com**. Product and privacy policy: https://pathlyhq.com

## Safe harbor

We appreciate good-faith research. Please avoid testing against production accounts you do not own, and never access or modify other customers' data.
